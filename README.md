# Світ Боксу — сайт (Astro)

Головна сторінка боксерського клубу «Світ Боксу», Бровари.

## Запуск

```bash
npm install
npm run dev      # локально: http://localhost:4321
npm run build    # готовий сайт у папці dist/
npm run preview  # перегляд зібраної версії
```

Потрібен Node.js 18.20+ (краще 20 або 22).

## Структура

```
src/
  pages/index.astro        головна: збирає секції по порядку
  layouts/Base.astro       <head>, шрифти, мета-теги
  styles/global.css        кольори, шрифти, кнопки, рамки фото — спільне для всіх секцій
  components/              кожна секція — окремий компонент зі своїми стилями і скриптом
    Hero.astro             перший екран з канатами рингу
    Marquee.astro          біжучий рядок
    Programs.astro         Раунд 01 · Програми
    Club.astro             Раунд 02 · Клуб
    HeavyBag.astro         Між раундами · Груша
    Coaches.astro          Раунд 03 · Тренерський склад
    Champions.astro        Раунд 04 · Чемпіони
    VideoBrief.astro       ТЗ для відеографа (заглушка під фонове відео)
    Life.astro             Раунд 05 · Більше, ніж зал
    Reviews.astro          Раунд 06 · Відгуки
    FirstTraining.astro    Раунд 07 · Перше тренування + FAQ
    Signup.astro           Раунд 08 · Форма запису
    PagesNav.astro         посилання на сторінки Розклад / Ціни / Як дістатись
    Scoreboard.astro       табло раунду (знизу зліва)
    MobileBar.astro        панель запису на телефоні
    Footer.astro           футер
    RoundLabel.astro       підпис «Раунд 01 · …»
  data/
    site.ts                телефон, адреса, години, меню, соцмережі
    content.ts             тексти секцій: програми, тренери, чемпіони, відгуки, FAQ…
  scripts/                 спільні скрипти: звук гонга, анімації заголовків
public/img/                фото
```

## Як редагувати контент

Більшість текстів — у `src/data/site.ts` і `src/data/content.ts`.
Текст у [квадратних дужках] — це заглушка: на сайті вона підсвічується рожевим,
поки її не замінять справжнім текстом.

## Що ще треба підключити

- **Форма запису** зараз лише перевіряє поля і показує «Дзінь!». Відправку заявки
  (Telegram-бот, пошта або CRM) треба додати в `Signup.astro`, місце позначене `TODO`.
- Посилання на Telegram і Viber — у `src/data/site.ts`.
- Сторінки Розклад, Ціни, Як дістатись — поки ведуть на `#`.
- Фото з Unsplash тимчасові, до фотосесії в залі.
- У `Base.astro` стоїть `noindex`, щоб чернетку не індексували пошукові системи. Прибрати перед запуском.
